01. EXECUTIVE SUMMARY
---------------------

Oil India Limited jaise large industrial organisation mein safety management ek
simple form-filling activity nahi hai. Operations 100+ sites par spread hain,
workforce geographically distributed hai, kaam high-risk hai aur workforce mein
engineers, operators, helpers, labourers aur contractors sab included hain.

Current challenge yeh hai ki safety reports ka volume bahut high hai, lekin
analysis manual aur delayed hai. Ek report alag se low-risk lag sakti hai, lekin
same site, same shift, same equipment ya same PPE issue ke saath combine karne par
woh Serious Injury and Fatality, ya SIF, precursor ban sakti hai.

Proposed system ek AI/NLP-powered Safety Intelligence Engine hai jo:

- Mobile app, web dashboard, SMS, call centre aur paper forms se reports leta hai.
- Hindi, Assamese aur English reports ko samajhta hai.
- Report se hazards, height, PPE, equipment, location, worker aur severity jaise
  entities extract karta hai.
- Historical safety records ke saath pattern matching karta hai.
- 75+ risk factors ke basis par explainable SIF score banata hai.
- Risk ke hisaab se right manager ko alert bhejta hai.
- Corrective action, deadline, owner aur evidence tracking automatically create
  karta hai.
- Feedback se continuously improve hota hai.

Expected business and safety outcomes:

- Serious incidents mein projected 70-80 percent reduction.
- Report analysis time mein approximately 85 percent reduction.
- Incident se alert tak target response time 30 minutes se kam.
- Near-miss and unsafe-condition reports ki 100 percent coverage.
- Target model accuracy approximately 85-89 percent after pilot validation.
- Projected annual net savings Rs. 8-13 Crore.
- Potentially 1.5-4 serious injuries or lives saved annually.
- Safety culture reactive se proactive banega.

Important note: Yeh system human safety officers ko replace nahi karega. Yeh
unko faster, consistent aur data-backed decision support dega.

03.3 HIDDEN PATTERN EXAMPLE 1
-----------------------------

Report: "Worker stairs par slip hua, lekin khud ko sambhal liya."

Manual classification: Near-miss, low risk.

Hidden context:

- Stairs approximately 40 feet high the.
- Guardrail broken tha, jo alag report mein mention hua tha.
- Same location par 6 mahine mein 3 similar incidents hue the.
- Next event fall ya fatality ho sakta tha.

AI system agar height, broken guardrail, location aur history ko connect karega,
to risk classification critical ho sakti hai.

03.4 HIDDEN PATTERN EXAMPLE 2
-----------------------------

Report: "Safety harness properly secured nahi tha."

08. NLP PROCESSING PIPELINE
---------------------------

SAMPLE INPUT
------------

"Worker 50 feet par drilling pipe se cut hua. Helmet tha lekin gloves nahi
the. Do log witness the."

LANGUAGE DETECTION
------------------

Detected language: Hinglish/Hindi mix.
Confidence: 0.98.

NORMALIZATION
-------------

50 feet -> 50_ft -> 15.24_m.
Gloves nahi the -> PPE gloves missing.
Cut hua -> laceration or hand injury candidate.

NAMED ENTITY RECOGNITION
------------------------

- HEIGHT: 50 feet.
- EQUIPMENT: drilling pipe.
- INJURY: laceration or cut.
- PPE: helmet yes, gloves no.
- WITNESSES: 2.
- LOCATION: site from user/session metadata.
- REPORTER: employee ID from authenticated user.

SEMANTIC ANALYSIS
-----------------

- Incident type: unsafe act plus unsafe condition.
- Height: critical context.
- PPE non-compliance: high risk.
- Sharp/rotating equipment: high risk.
- Severity text indicator: deep cut.

STRUCTURED OUTPUT
-----------------

{
  incident_type: "Unsafe Act + Unsafe Condition",
  injury_type: "Laceration",
  height_involved: 50,
  equipment: ["Drilling Pipe"],
  ppe: { helmet: "YES", gloves: "NO" },
  witnesses: 2,
  confidence_score: 0.95
}

IMPORTANT DESIGN DECISION
-------------------------

NLP ka output final truth nahi maana jayega. Confidence low hone par:

- Human review queue create hogi.
- Worker ya supervisor clarification request milega.
- Original voice/text evidence preserve rahega.
- Final corrected label training feedback banega.


09. RISK SCORING ALGORITHM
--------------------------

COMPREHENSIVE FORMULA
---------------------

SIF_SCORE =
0.25 x Injury_Risk +
0.20 x Height_Risk +
0.20 x PPE_Risk +
0.15 x Pattern_Risk +
0.12 x Exposure_Risk +
0.08 x Environmental_Risk + adjustment factors

COMPONENTS
----------

1. Injury Risk
   Fatal/critical: 95.
   Serious injury: 80-90.
   Moderate injury: 60-70.
   Minor injury: 30-50.
   Near-miss: 20-40.

2. Height Risk
   0-6 ft: 10.
   6-15 ft: 30.
   15-30 ft: 60.
   30-50 ft: 80.
   Above 50 ft: 95.

3. PPE Risk
   Helmet missing: +30.
   Gloves missing during high-risk work: +35.
   Harness missing above 15 ft: +40.
   Safety shoes missing: +15.
   Improper PPE use: +10.

4. Pattern Risk
   Similar incidents.
   Same site.
   Same crew.
   Same shift.
   Increasing trend.
   Same root cause.

5. Exposure Risk
   Number of workers exposed.
   Frequency of task.
   Duration.
   Number of shifts.

6. Environmental Risk
   Outdoor exposure.
   Confined space.
   Heat, wind, wet surface.
   Noise, fumes and visibility.

EXAMPLE CALCULATION
-------------------

Injury Risk = 85.
Height Risk = 80.
PPE Risk = 35.
Pattern Risk = 95.
Exposure Risk = 75.
Environment Risk = 60.

Score = (0.25 x 85) + (0.20 x 80) + (0.20 x 35) +
        (0.15 x 95) + (0.12 x 75) + (0.08 x 60)

Score = 72.3 / 100.

Interpretation:

- Risk Level: HIGH.
- Alert Priority: URGENT.
- Confidence: approximately 92 percent.
- Escalation: Site Manager and Regional Safety Officer.
- Action: secure area, medical check, investigation and training.

EXPLAINABILITY REQUIREMENT
--------------------------

System sirf score nahi dikhayega. Score ke reasons visible honge:

- 50 ft height.
- Missing gloves.
- Five similar incidents.
- Increasing trend.
- 300 workers exposed.

Helmet aur safety shoes compulsory hain. Buddy System follow hoga. Har do

11.2 ZONE-BASED SAFETY
----------------------

RED ZONE:
- High voltage, hot surfaces, gas exposure or restricted activity.
- Full PPE.
- Supervisor permission required.

YELLOW ZONE:
- Crane movement, heavy machinery or overhead work.
- Helmet mandatory.
- Overhead awareness required.

GREEN ZONE:
- Normal work area.
- Standard safety rules apply.

11.3 TRAINING PROGRAMME
-----------------------

Day 1: Orientation, site tour and emergency procedure.
Day 2-3: Hazard identification, PPE, first aid and competency exam.
Day 4-5: Job-specific hands-on training and final check.
Every 6 months: Refresher training.

-----------------------

Negative points:

Reward example:

Contingency: Pilot extension and manual review for border cases.

Probability: Medium-high.
Impact: Incomplete context and wrong analysis.
Mitigation: Early ETL testing, schema validation, dedicated integration team.
Contingency: Manual import fallback and phased read-only sync.

RISK 3: LOW USER ADOPTION
Probability: Medium.
Impact: System underutilization.
Mitigation: Training, site champions, simple voice reporting, recognition.
Contingency: On-site support and extended pilot.

RISK 4: ALERT FATIGUE
Probability: Medium.
Impact: Supervisors alerts ignore kar sakte hain.
Mitigation: Calibrated thresholds, feedback loop, priority tiers.
Contingency: Safety Officer review for false alarm patterns.

RISK 5: WORKER PRIVACY CONCERN
Probability: Medium.
Impact: Trust and adoption issue.
Mitigation: Consent, wake-word recording, clear safety-only policy.
Contingency: Disable optional recording and use text/SMS channel.

RISK 6: BUDGET OVERRUN
Probability: Medium.
Impact: Delay or scope reduction.
Mitigation: Phased funding, 20 percent contingency, priority features.
Contingency: Defer non-critical features and extend timeline.

RISK 7: REGULATORY OR SECURITY ISSUE
Probability: Low-medium.
Impact: Legal and reputation risk.
Mitigation: Encryption, RBAC, audit trail, legal review, penetration testing.
Contingency: Incident response team and controlled data shutdown.

19. LIKELY SIH QUESTIONS AND ANSWERS
-------------------------------------

Q1. AI galat risk score de to kya hoga?
A: Har score ke saath confidence value aur reason breakdown hoga. Low-confidence
cases human review queue mein jayenge. Pilot phase mein AI prediction manual
review ke parallel validate hoga.

Q2. Remote drilling site par network nahi hoga to?
A: Offline-first forms aur edge keyword detection use honge. Report locally
encrypted store hogi aur connectivity restore hote hi synchronize hogi.

Q3. Kya yeh system workers ko monitor ya spy karega?
A: Nahi. Voice recording wake word ya explicit report action ke baad hogi.
Clear consent, safety-only purpose, access control aur retention policy enforce
hogi. System disciplinary surveillance ke liye nahi hai.

Q4. Hindi aur Assamese ko kaise samjhega?
A: Language detection, multilingual ASR/NLP, Indic language training data,
regional terminology dictionary aur human feedback loop use honge. Low
confidence translation automatic fact nahi maani jayegi.

Q5. Existing SAP/HRIS system replace hoga?
A: Nahi. API-led integration layer existing systems ko connect karegi. Pehle
read-only sync se start karke validated two-way integration ki ja sakti hai.

Q6. False alarms se alert fatigue kaise avoid karoge?
A: Confidence thresholds, risk tiers, feedback button, false-alarm labels aur
model tuning. Critical alert ke liye multi-factor confirmation and escalation
rules honge.

Q7. Data security kaise ensure hogi?
A: TLS 1.3, AES-256, SSO/OAuth, RBAC, secrets management, audit trail,
retention policy, backups and periodic security testing.

Q8. Pilot success kaise measure hoga?
A: Accuracy, response time, user adoption, report coverage, false alarm rate,
action closure time, incident trend and ROI.

Q9. AI safety officers ki jobs replace karega?
A: Nahi. Manual reading reduce hogi. Safety officers investigation, field
verification, root cause analysis, training aur decision-making par focus karen.

Q10. Implementation cost justify kaise hoga?
A: Pilot se actual baseline and savings measure honge. Projected payback 1.5-2.5
months hai, lekin final ROI conservative pilot data se decide kiya jayega.

Q11. Agar worker report hi nahi karta to?
A: AURA voice, QR guides, SMS, supervisor entry, call centre and paper/OCR
multiple channels honge. Toolbox Talk and buddy system reporting culture build
karenge.

Q12. Explainability kaise milegi?
A: Score ke saath factors, matched history, trend, confidence, root cause
indicators and recommended actions visible honge.
